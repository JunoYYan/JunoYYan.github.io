## 👋 About

This repository holds the source for my personal website and portfolio. It's where I share who I am, what I've built, and what I'm working on, across both software and hardware.

## ✨ Features

- **Responsive layout** that works on desktop and mobile
- **Light / dark mode** toggle that remembers your choice
- **Filterable project grid** (Code · Design · Research)
- **Experience timeline** and contact section
- **Zero dependencies**: plain HTML, CSS, and JavaScript
